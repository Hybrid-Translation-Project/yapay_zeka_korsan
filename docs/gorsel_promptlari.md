# Görsel Üretim Promptları

Aşağıdaki promptlar, ana ekran veya sunum için ek görsel üretmek amacıyla kullanılabilir.

## Ana Ekran Görseli

```text
Create a stylized 3D isometric game splash screen for a Turkish AI rescue agent game named "Akıllı Kurtarma Ajanı". Scene: a post-earthquake city grid with blocked roads, rubble, red danger zones, blue route markers, yellow aid package crates, a small hospital with a purple medical cross, and a compact rescue robot agent. The mood should be tactical, serious, high quality, game UI friendly, dark olive and charcoal background with teal, blue, amber, and red accents. No text in the image. Clean low-poly 3D style, readable shapes, not photorealistic, not cartoonish, suitable for a university AI hackathon project.
```

## Robot Ajan Tasarımı

```text
Design a small 3D rescue robot game character for a grid-based AI pathfinding game. The robot should look compact, smart, and functional, with a dark graphite body, teal glowing visor, small antenna, and subtle blue route-light accents. Low-poly 3D style, game asset concept, front three-quarter view, transparent background, no text.
```

## Yardım Paketi İkonu

```text
Create a low-poly 3D aid package crate for a disaster rescue game. Yellow-orange medical supply box, dark straps, small cross-like banding, clean game asset, isometric angle, transparent background, no text.
```

## Hastane / Hedef Modeli

```text
Create a low-poly 3D hospital target building for an isometric rescue pathfinding game. Small white building with a purple medical cross, clean rectangular shape, readable from far away, tactical game style, transparent background, no text.
```
