# Gorsel Uretim Promptlari

Asagidaki promptlar, ana ekran veya sunum icin ek gorsel uretmek amaciyla kullanilabilir.

## Ana Ekran Gorseli

```text
Create a stylized 3D isometric game splash screen for a Turkish AI pirate pathfinding game named "Korsan Hazine Avcisi". Scene: a tropical Caribbean island grid with rock obstacles, ship wrecks, enemy pirate ships firing cannons, gold treasure chest crates, and a compact pirate ship sailing through routes. The mood should be adventurous, mysterious, high quality, game UI friendly, turquoise sea and sandy beach background with gold, wood, and red accents. No text in the image. Clean low-poly 3D style, readable shapes, not photorealistic, not cartoonish, suitable for a university AI hackathon project.
```

## Korsan Gemisi Tasarimi

```text
Design a small 3D pirate ship game character for a grid-based AI pathfinding game. The ship should look compact, detailed, and functional, with wooden hull, dark sails featuring a skull emblem, and subtle blue route-light accents. Low-poly 3D style, game asset concept, front three-quarter view, transparent background, no text.
```

## Hazine Sandigi Ikonu

```text
Create a low-poly 3D treasure chest overflowed with gold coins and gems for an isometric pirate game. Dark wood straps, golden locks, clean game asset, isometric angle, transparent background, no text.
```

## Korsan Kalesi / Hedef Modeli

```text
Create a low-poly 3D pirate fortress castle gate with a skull flag for an isometric pathfinding game. Dark stone building, pirate skull flag waving, readable from far away, tactical game style, transparent background, no text.
```
